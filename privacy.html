Deltalo Publisher (YouTube API Services)

"Deltalo Publisher" is an internal command-line tool used only by Deltalo staff. It uses YouTube API Services to upload Deltalo's own promotional videos (game trailers and Shorts) to the official Deltalo YouTube channel and to read back the status of those uploads. It is not offered to the public and has no end users other than Deltalo.

  • Data accessed: only the Deltalo channel's own basic information (channel ID and title) and the videos it uploads (ID, title, privacy and processing status). It does not access any other user's data, comments, subscribers, analytics or private information.
  • Storage: the OAuth access/refresh token is stored only on Deltalo's own computer, never on a server and never shared. Video IDs are kept in our project files to link trailers from our Google Play store listings.
  • Sharing: no data obtained through YouTube API Services is sold or shared with third parties.
  • Revoking access: access can be revoked at any time from the Google security settings page; the local token is then deleted.

By using YouTube API Services we are bound by the YouTube Terms of Service, and data is processed according to the Google Privacy Policy.
